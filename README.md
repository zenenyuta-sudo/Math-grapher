# Math Grapher

Calculator (nCr, nPr, gcd, lcm, mod, device-keyboard toggle) · 2D grapher (5 graph types, write/draw on the graph, domain & range) · 3D grapher (9 types) · MathSolver (row-by-row steps + check) · Settings (themes, ranges) · Help · About.
Static PWA — no build step, no server, no paid services, works offline after the first load.

Deploy to GitHub Pages: upload every file in this folder to a repository, then Settings → Pages → Deploy from branch.

Files: index.html · style.css · app.js · gg.js (menu/screens) · engine.js (shared safe parser + math, no eval) · grapher.js (2D) · grapher3d.js (3D) · calc.js · solver.js · annot.js (notes on graph) · theme.js (colors) · manifest.json · service-worker.js · assets/
