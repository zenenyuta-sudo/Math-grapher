دەستپێک

Math Grapher پێنج بەشی هەیە: Calculator (ژمێرەر)، 2D grapher، 3D grapher، MathSolver و Settings. هەموویان بزوێنەرێکی ماتماتیکی هاوبەش بەکاردەهێنن، بۆیە هەمان شێوازی نووسین لە هەموو بەشەکاندا کار دەکات.

ئەپەکە بێ ئینتەرنێت کار دەکات. بۆ دامەزراندن لەسەر مۆبایل، لە وێبگەڕەکەت Add to Home Screen هەڵبژێرە.

شێوازی نووسینی دەربڕین
  • کۆکردنەوە و لێکردن: + -، لێکدان: * یان ×، دابەشکردن: / یان ÷، توان: ^ (نموونە x^2).
  • ڕەگ: sqrt(x) یان √(x)، ڕەگی سێیەم: cbrt(x).
  • نرخە نەگۆڕەکان: pi یان π، e، inf.
  • فەنکشنەکان: sin cos tan cot sec csc، asin acos atan، sinh cosh tanh، asinh acosh atanh، log (بنەمای ١٠)، log2، ln، exp، abs، floor، ceil، round، sign.
  • فاکتۆریال 5!، ڕێژە %، خاڵی ناوەڕاست وەک 2x (واتە 2*x) پشتگیری دەکرێت.
  • پارەنتێز: ( ). کەوانەی [ ] و { } بە هەمان واتا دەخوێنرێنەوە.
Calculator — ژمێرەر

نووسین: دەتوانیت بە دوگمەکانی ئەپەکە بنووسیت یان بە کیبۆردی ئامێرەکەت. دوگمەی Aa لە تەنیشت خانەی نووسین کیبۆردی ئامێر دەکاتەوە؛ بۆ گەڕانەوە بۆ دوگمەکانی ئەپەکە دووبارە لێی بدە. لە کۆمپیوتەر، بەبێ هیچ دوگمەیەک دەتوانیت راستەوخۆ بنووسیت.

کورسەر: کلیک لە هەر شوێنێکی دەربڕینەکە بکە بۆ گۆڕینی شوێنی نووسین. دوگمەکانی ⇦ و ⇨ کورسەر دەجوڵێنن، Del پیتێک دەسڕێتەوە، C خانەکە پاک دەکاتەوە (ئەگەر بەتاڵ بوو، مێژووەکە).

دوگمەی Graph: هاوکێشەکەی ناو خانەکە دەنێرێت بۆ گرافی ٢ ڕەهەند، نموونە y=x^2-4 یان x^2+y^2=9. ئەگەر بەبێ y= بنووسیت، وەک y=... دادەنرێت.

2nd: کلیلەکان دەگۆڕێت (sin ← sin⁻¹، log ← 10ˣ ...). func: ئامرازەکانی ئاسانکردن، چارەسەر، لێکدانەوە (d/dx)، ئینتیگڕاڵ، و فەنکشنی زیاتر. const: نرخە نەگۆڕە زانستییەکان.

فەنکشنی زیاتر: nCr(n,r) بۆ کۆمبینەیشن، nPr(n,r) بۆ پێرمیوتەیشن، gcd(a,b) دابەشکەری هاوبەشی گەورە، lcm(a,b) لێکدراوی هاوبەشی بچووک، mod(a,b) ماوەی دابەشکردن، rand() ژمارەی هەڕەمەکی.

ئەنجام: ans ئەنجامی پێشوو. کلیک لەسەر هەر ئەنجامێک لەبەری دەگرێتەوە. «هەنگاوەکان» بکەرەوە بۆ بینینی چۆنیەتی چارەسەرکردن. هەر ئەنجامێک نیشان دەدرێت «وردە» یان «نزیکەیی».

2D grapher — گرافی دوو ڕەهەند

زیادکردنی گراف: دوگمەی ☰ (لای ڕاستی سەرەوە) لیستی گرافەکان دەکاتەوە. New graph بکە و جۆر هەڵبژێرە: y(x)، x(y)، r(θ)، x(t),y(t)، F(x,y).

پارامیتەر: هەر پیتێک جگە لە x، y، t، θ وەک پارامیتەر دادەنرێت و سلایدەری بۆ دروست دەبێت، نموونە a*x^2+b*x+c. ماوەی سلایدەر دەتوانیت بگۆڕیت.

جووڵە: ڕاکێشان = جووڵاندنی گراف، چەرخی ماوس یان دوو پەنجە = زووم، دوگمەی ⟲ = گەڕانەوە بۆ دۆخی سەرەتایی.

ئامرازەکان (△): ڕیشەکان، بڕینی y، گەورەترین/بچووکترین خاڵ، خاڵی بڕین، بوار و مەودا (Domain & Range)، لێکدانەوە f′(x)، هێڵی لیکەوتوو (Tangent)، و بەهای f(x₀). دوگمەی ✕ راستەوخۆ خاڵی بڕینی نێوان گرافەکان نیشان دەدات.

نووسین لەسەر گراف (✎): دوگمەی ✎ تووڵبارێک دەکاتەوە: Move بۆ جووڵاندنی گراف، Pen بۆ ڕەسمکردن، Text بۆ نووسینی تێبینی، Erase بۆ سڕینەوە، ڕەنگ و ئەستووریی قەڵەم، Undo و Clear. نووسینەکان بە هەمان شوێنی گرافەوە دەبەسترێنەوە و لەگەڵ زووم و جووڵاندندا دەجوڵێن. دوگمەی Domain/Range بوار و مەودای ئەو گرافە هەڵبژێردراوە لەسەر شاشە دەنووسێت. وێنەی گرافەکە (دوگمەی ⇪) نووسینەکانیش لەخۆ دەگرێت.

3D grapher — گرافی سێ ڕەهەند

٩ جۆر: z(x,y)، x(y,z)، y(x,z)، x/y/z(ρ,φ)، r(θ,φ)، xyz(u,v)، و F(x,y,z)=0. تەنها دەربڕین بنووسە، نموونە sin(sqrt(x^2+y^2)). بۆ F(x,y,z) نموونە x^2+y^2+z^2=9.

شێوازی پیشاندان (سەرەوە): خاڵ، تۆڕ (Wireframe)، ڕووی پڕ، و ڕوو + هێڵ.

کۆنتڕۆڵ: ڕاکێشان = سووڕاندن، چەرخ یان دوو پەنجە = زووم، دووجار کلیک = گەڕانەوە. پانێڵی کۆنتڕۆڵی خوارەوە دوگمەی زووم، سووڕاندن بە ئاراستە، بینینی سەرەوە/پێشەوە/لا/Iso، سووڕانی خۆکار (Auto)، پیشاندان/شاردنەوەی تەوەرەکان و ژمارەکان و زەوی (Floor)، زیادکردن/کەمکردنی وردی (Detail)، و گۆڕینی ماوە (Range) هەیە.

MathSolver — چارەسەرکەر

هەر هاوکێشەیەک لە هێڵێکی جیاوازدا بنووسە، ئینجا Solve بکە. دوگمەکانی سەرەوەی خانەکە پیت و هێماکان زیاد دەکەن، و نموونەکان بە یەک کلیک دەچنە ناو خانەکە.

  • سیستەمی هێڵی: بە ڕێگەی Gauss–Jordan چارەسەر دەکرێت. هەموو کرداری ڕیزەکان (R₂ ← R₂ − 2·R₁ ...) لەگەڵ ماتریکسەکە نیشان دەدرێت. ئەگەر چارەسەر نەبوو یان بێ‌کۆتا بوو، ڕوون دەنووسێت.
  • هاوکێشەی یەک گۆڕاو: هەنگاو بە هەنگاو چارەسەر دەکرێت.
  • سیستەمی نا‌هێڵی: بە شێوازی ژمارەیی (Newton) چارەسەر دەکرێت و ئەنجامەکان «نزیکەیی» دەنیشاندرێن.
  • پشکنین: ئەنجامەکان دەگەڕێنرێنەوە ناو هاوکێشەکان بۆ دڵنیابوون لە دروستییان.
Settings — ڕێکخستن
  • Appearance: ڕەنگی ئامادەکراو (Dark، Light، Ocean، Purple، Forest، Sunset) هەڵبژێرە، یان ڕەنگەکان خۆت بگۆڕە: Accent، Background، Panels، Top bar، Text، و ڕەنگی پشتی گراف.
  • 2D grapher: ماوەی X و Y بنووسە و Apply بکە، یان لە ماوە خێراکان هەڵبژێرە. Equal scale پێوانەی X و Y یەکسان دەکات.
  • 3D grapher: ماوەی ±R و ژمارەی خانەکانی تۆڕ (N). N زیاتر = وردتر بەڵام هێواشتر.
  • Calculator: بەکارهێنانی کیبۆردی ئامێر، و پاککردنەوەی مێژوو.
  • هەموو ڕێکخستنەکان خۆکار پاشەکەوت دەکرێن.
چارەسەری کێشەکان
  • کیبۆردی ئامێر دەرناکەوێت: دوگمەی Aa لە ژمێرەر دابگرە یان لە Settings چالاکی بکە.
  • گرافەکە نادیارە: دوگمەی ⟲ بکە یان لە Settings ماوەکە بگۆڕە. ئەگەر ماوەکە زۆر بچووک یان گەورە بێت گرافەکە دەرناکەوێت.
  • گۆشەکان: ئەگەر sin(90) ئەنجامی ١ نادات، لە Settings دۆخی گۆشە لە Radians بۆ Degrees بگۆڕە.
  • ئامرازەکانی گراف: تەنها بۆ گرافی y(x)ـی ڕوون کار دەکەن، نەک هاوکێشە ئاماژەکراوەکان.
  • هەڵە لە ئەنجامدا: ئەپەکە ئەنجامی نادروست دانانێت؛ ئەگەر کرداری پشتگیری‌نەکراو بێت، هەڵەی ڕوون نیشان دەدات.
  • هەموو شتێک لەناو چوو: لە Settings، Reset everything ئەپەکە دەگەڕێنێتەوە بۆ سەرەتا.
